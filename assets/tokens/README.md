# Animal token artwork

The four PNGs in this folder are transparent cutouts prepared from the user's supplied images using built-in image-generation edit mode. Originals were retained outside the project. These are camera-facing image pieces on 3D bases, not full 3D animal models. They share the existing token movement, selection, Jail marker and player identity; no gameplay state was changed. The same images appear in the HTML player icons. Original geometry remains a loading/error fallback and supports legacy saved animals.

## Final prompts

### frog

Edit the supplied reference image into a clean transparent game-token cutout of the single pale green sitting frog with huge glossy eyes. Preserve the exact character design, pose, proportions, face, colours, material and 3D-rendered appearance as faithfully as possible. Remove ALL background, ground plane, cast shadows, other subjects, text and decoration. Actual transparent alpha background, NOT a checkerboard drawing or a solid colour. One single character only. Entire animal including ears, hair, feet and tail visible. Center the isolated character within a square image with minimal even padding, fit the longer dimension to about 92% of image size, no clipping. This is background removal / isolation, not a redesign. Output PNG with transparency.

### monkey

Create a transparent PNG game asset from the reference. Isolate only the main brown monkey holding a banana in the upper half. Single full-body monkey cutout on transparent alpha background, suitable to composite directly over a 3D game scene. Keep the monkey's exact face, pose and warm brown colours. Exclude the two grey models, scenery, ground and cast shadow. Fill 90% of a square canvas with the complete character. Background must have alpha=0 outside the animal. Use transparent background output.

The initial monkey outputs were rejected because they contained painted checkerboards; the final PNG was verified to contain alpha transparency.
